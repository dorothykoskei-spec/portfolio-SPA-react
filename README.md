# My Portfolio App

# Description
This is a simple React app built with Vite.  
It helps you add, search, and delete projects.

# Deployed link

## Features
- Add new projects
- Search projects by name
- Delete projects
- Built with React Components

## How to Run
1. Install packages:npm installjavascript
2. Start the app:npm run devjavascript
3. Open the link it gives you in the browser

## Project Files
- `App.jsx` - Main file. Holds all project data
- `ProjectForm.jsx` - Form to add new projects
- `ProjectList.jsx` - Shows projects and search + delete button
- `App.css` - Styling
